UEK FUNDAMENTALS OF PROGRAMMING - 08 FILE HANDLING
Source: Wklejony tekst(8).txt (Janusz Stal)

INSTRUCTIONS:
1) Unzip and copy contents of 08-FileHandling into your repo's 08-FileHandling folder.
2) Open that folder in VS Code, or use terminal:
   cd 08-FileHandling
   python 1-5.py
   python 2-2.py
   python 4-10.py
3) Python files use the location of THIS .py file, so input files can be found
   even if you launch scripts from a different working directory.
4) Input-based scripts: 2-5.py, 3-5.py, 4-5.py, 4-7.py, 4-8.py.
5) 4-6.py imports emails.py; keep both in the same folder.
6) read_file.py is INTENTIONALLY supposed to raise FileNotFoundError;
   read_file_try_except.py handles that error.
7) 3-2_regexone.txt is an interactive WEBSITE assignment, not a .py exercise.
8) 3-3_regex101_patterns.txt lists patterns to paste into Regex101.com.

IMPORTANT: The original worksheet refers to input files without providing them.
The TXT/CSV/email data in this ZIP are SAMPLE TEST DATA assembled for
practice, NOT official UEK teaching files. Replace those files with the
original class datasets if you have them. Your exact output can then differ.
The provided books.csv layout, clothing.csv headers, raw email format and
report amount format are ASSUMPTIONS based on the exercise descriptions.
Adjust column names and patterns if the originals are structured differently.

NAMES follow CHAPTER-ITEM numbering in the source document, including theory
items. Section 1: 1-4 through 1-9; section 2: 2-1 through 2-5;
section 3: 3-3 through 3-5 + web exercise note;
section 4: 4-5 through 4-13 + item 4 example scripts.

No external Python packages are required. Only Python standard library.
